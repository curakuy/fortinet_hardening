FortiOS 7.4 & 7.6 Açık Port Matrisi (Incoming & Outgoing)

FortiOS-7.4-Ports.pdf ve FortiOS-7.6.0-Ports.pdf dokümanlarına göre kritik servis portları.

Port / Protokol Servis / İşlev Sıkılaştırma Önerisi (7.4 & 7.6)
TCP 443 / 8443 HTTPS Yönetim Arayüzü, REST API, ZTNA Proxy admin-sport değiştirilmeli, WAN üzerinde local-in-policy ve trusthost ile sınırlandırılmalı.
TCP 22 SSH CLI Yönetimi admin-ssh-port değiştirilmeli, admin-ssh-v1 disable yapılmalı.
UDP 500, 4500 & TCP 11443 IPsec VPN (IKEv2 & 7.6 TCP Kapsülleme) FortiOS 7.6'da SSL-VPN yerine set transport udp-fallback-tcp ve set ike-tcp-port 11443 önerilir.
TCP 8008, 8010, 8015, 8020 Web Filter Override Portları Kullanılmıyorsa config webfilter fortiguard altında set close-ports enable ile kapatılmalıdır.
TCP 8013 / TCP 8014 FortiClient EMS & Security Fabric Sadece yetkili EMS sunucusu ve iç ağ IP'lerine izin verilmelidir.
TCP 853 (DoT) / TCP 443 FortiGuard Anycast & Şifreli DNS update.fortiguard.net, service.fortiguard.net ve DNS için set protocol dot kullanılmalıdır.

FortiOS 7.6 Hazır Geçiş Şablonları (IPsec IKEv2 TCP & Local-In Virtual Patching)

1. SSL-VPN Yerine IPsec IKEv2 (TCP 11443 Fallback)
config system settings
    set ike-tcp-port 11443
end
config vpn ipsec phase1-interface
    edit "RA-IPsec-IKEv2-76"
        set type dynamic
        set interface "wan1"
        set ike-version 2
        set peertype any
        set net-device disable
        set mode-cfg enable
        set proposal aes256gcm-prfsha384
        set dpd on-idle
        set dhgrp 20 21
        set transport udp-fallback-tcp
        set eap enable
        set eap-identity send-request
        set ipv4-start-ip 10.212.134.10
        set ipv4-end-ip 10.212.134.200
        set ipv4-netmask 255.255.255.0
    next
end
2. Local-In Virtual Patching & Malicious/Tor Engelleme (7.6)
config firewall local-in-policy
    edit 1
        set intf "wan1"
        set srcaddr "all"
        set dstaddr "all"
        set service "ALL"
        set schedule "always"
        set action deny
        set internet-service-src enable
        set internet-service-src-name "Malicious-Malicious.Server" "Tor-Exit.Node" "Tor-Relay.Node"
        set logtraffic all
    next
    edit 2
        set intf "wan1"
        set srcaddr "CORP_ADMIN_SUBNETS"
        set dstaddr "all"
        set action accept
        set service "HTTPS" "SSH"
        set schedule "always"
        set virtual-patch enable
        set logtraffic all
    next
end
